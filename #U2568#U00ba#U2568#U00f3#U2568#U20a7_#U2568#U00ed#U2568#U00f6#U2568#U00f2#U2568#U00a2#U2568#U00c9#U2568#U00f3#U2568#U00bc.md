# TheStarth v92 — что сделать после обновления

## 1. GitHub (сайт)
1. Распакуйте архив и **замените файлы** в репозитории `r1lans/fedabeta` с сохранением папок
   (`docs/`, `firebase-backend/` — тоже). Новые файлы: `attendance-journal.js`, `admin-attendance.js`.
2. Commit → Push. Cloudflare Pages сам выложит сайт за 1–2 минуты.

## 2. Firebase (обязательно, иначе новое не заработает)
1. console.firebase.google.com → проект **thestarth-b7620** → **Firestore Database → Rules**.
2. Удалите всё, вставьте целиком файл `firebase-backend/firestore.rules` → **Publish**.
3. Тариф **Blaze** (если ещё нет) и **бюджет с уведомлениями**: Usage and billing → Details & settings → Budget alerts
   (например $20 / $50). Уведомления только предупреждают, не останавливают расходы.
4. Новые индексы не нужны. Если в консоли браузера появится ошибка «The query requires an index» — нажмите на ссылку
   в ошибке, Firebase создаст индекс сам.

## 3. Cloudflare
1. **Workers & Pages → thestarth (Pages) → Deployments** — проверьте, что последний деплой «Success».
2. **Settings → Variables and Secrets** — должны быть `TURN_KEY_ID` и `TURN_KEY_API_TOKEN` (видео через TURN).
   Если их нет: **Realtime → TURN Server → Create** и вставьте ключи сюда, затем Retry deployment.
3. Кэш чистить не нужно (версии скриптов стали `?v=92`). Если у кого-то старая страница — **Caching → Purge Everything**.
4. Воркеры (`starth-ai`, бот) в этом обновлении **не менялись** — их не трогайте.

## 4. Проверка после заливки (10 минут)
- Учитель: «Мои группы» → группа → «Посещаемость»: сегодня отмечается, прошлые дни заблокированы.
- Админ: «Посещаемость» → выберите группу → можно отметить любой день.
- «Партнёры» → «+ Создать партнёра» → тестовый партнёр с вашим вторым аккаунтом → у него пропал раздел «Зарплата».
- «Олимпиада» → создать тестовую на завтра → зарегистрироваться со второго аккаунта → «Регистрации».
- Telegram-бот → приложение → открыть чат → отправить сообщение. Оно должно дойти на сайт.

## 5. Сообщения в приложении бота
Исправлено в `tg-app.js` и `firebase-config.js`: в Telegram сайт теперь работает с базой через «long polling»
(WebView Telegram рвал обычное соединение, и сообщение «висело»), чат подгружается, если его ещё нет в списке,
а при ошибке показывается причина («нет связи» / «нет доступа к чату») и текст не пропадает.
Если всё ещё не отправляется — пришлите скриншот текста ошибки.
