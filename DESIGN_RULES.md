# Правила оформления TheStarth

1. **Никаких эмодзи на сайте.** Везде — SVG-иконки из `icons.js` (`Icons.svg('calendar')`, `Icons.svg('check')` и т.д.)
   или встроенный `<svg>` в том же стиле (24×24, stroke = currentColor, толщина 1.8–2).
   Нет нужной иконки — добавьте её в `icons.js`, а не ставьте эмодзи.
   Это касается кнопок, заголовков, статусов, сообщений, тостов, PDF-инструкций и скриншотов для них.
   Исключение — только сообщения Telegram-бота (там SVG невозможен).
2. Стрелки в тексте (→ ← ↑ ↓) — это типографика, их можно.
3. Цвета и токены — только переменные из `styles.css` (`--accent`, `--ink`, `--paper` …), чтобы работала тёмная тема.
