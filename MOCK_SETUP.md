# Mock-тесты и ИИ для составления тестов

## 1. Что нужно сделать один раз (без ИИ это уже работает)

1. **Опубликовать правила Firestore.** Firebase Console → Firestore → Rules → вставьте содержимое `firebase-backend/firestore.rules` → **Publish**.
2. **Опубликовать правила Storage** (нужны для загрузки аудио). Storage → Rules → вставьте `firebase-backend/storage.rules` → **Publish**.
3. Залить новые файлы на GitHub (список в конце).

## 2. Как создать тест (Админ-панель → Mock-тесты → «Новый тест»)

1. Впишите название (например, `Cambridge IELTS 19, Test 1`) и выберите раздел: Listening или Reading.
2. В каждой части (Part 1, Part 2…):
   - **Listening:** загрузите аудио этой части кнопкой «Загрузить mp3» (до 60 МБ) или вставьте ссылку.
   - Раскройте «Файл с заданием»: загрузите PDF / Word / текст с вопросами. Для Reading в этом же файле должен быть и текст для чтения. Файл с ответами необязателен, но с ним ответы будут точными.
   - Нажмите **«Составить с помощью ИИ»** (если ИИ подключён, см. ниже) и проверьте результат: вопросы, варианты и правильные ответы. Любое поле можно поправить руками.
3. Нажмите **«Сохранить и опубликовать»**. Тест сразу появится у учеников на странице Mock Exam.

Без ИИ-сервера: нажмите «Скопировать запрос для ИИ», вставьте его в ChatGPT или Claude, а ответ вставьте кнопкой «Вставить JSON».

**Важно:**
- Нужен PDF с **текстом**, а не сканом-картинкой (у скана нет текста, ИИ нечего читать).
- Картинки, схемы и карты из PDF не переносятся. Если в задании есть схема, опишите её словами в тексте вопроса.
- Для Listening ИИ не слышит аудио. Без файла ответов он оставит ответы пустыми, и вы впишете их сами.
- Не загружайте на сайт чужие защищённые материалы (книги Cambridge и т. п.) без разрешения правообладателя.

## 3. Как подключить ИИ (Cloudflare Worker, бесплатно)

ИИ нельзя вызывать прямо из сайта: ключ окажется в открытом коде. Поэтому нужен маленький посредник.

### Два варианта ИИ для составления тестов (по желанию, выберите один)

**Вариант А — бесплатный (Cloudflare Workers AI).** Ключ и оплата не нужны, есть дневной бесплатный лимит (актуальный размер смотрите в Cloudflare). Качество ниже, чем у Claude: тесты из файлов составляются хуже, ограничение на размер файла 18 000 символов (загружайте по одной части). Всегда просматривайте результат перед публикацией.
Как включить: в Worker → **Settings → Bindings → Add → Workers AI**, имя переменной строго `AI` → Deploy. Секрет `ANTHROPIC_API_KEY` добавлять не надо. Раздел 3.1 можно пропустить.

**Вариант Б — платный (Claude).** Лучшее качество, платите только за использование. Если заданы и ключ, и привязка `AI`, работает Claude.

### 3.1. Ключ от ИИ
1. Зайдите на https://console.anthropic.com → войдите → **API Keys** → **Create Key**, скопируйте ключ (он начинается с `sk-ant-`).
2. В разделе **Billing** пополните баланс (это отдельная оплата, не подписка Claude). Точные цены смотрите на сайте Anthropic. Одна часть IELTS обычно стоит небольшую сумму.

### 3.2. Посредник на Cloudflare
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. **Workers & Pages → Create → Create Worker**. Назовите, например, `starth-mock-ai` → **Deploy**.
3. Нажмите **Edit code**, удалите всё и вставьте содержимое файла `worker/mock-ai-worker.js` → **Deploy**.
4. **Settings → Variables and Secrets → Add**:
   - `ANTHROPIC_API_KEY` (тип **Secret**) — ключ из шага 3.1;
   - необязательно `ALLOWED_ORIGIN` (тип Text) — по умолчанию `https://thestarth.com`;
   - необязательно `FIREBASE_PROJECT_ID` (по умолчанию `thestarth-b7620`) и `MODEL` (по умолчанию `claude-sonnet-5-5`).
   Пароль `ADMIN_KEY` больше **не нужен**: посредник узнаёт, кто обращается, по входу в аккаунт на сайте.
5. Нажмите **Deploy** ещё раз. Адрес посредника виден вверху, он выглядит как `https://starth-mock-ai.ВАШ-АККАУНТ.workers.dev`.

### 3.3. Подключить к сайту
Откройте `mock-config.js` и впишите адрес:

```js
window.MOCK_AI_URL = 'https://starth-mock-ai.ВАШ-АККАУНТ.workers.dev';
```

Залейте файл на GitHub. Больше ничего вводить не нужно.

Защита: посредник отвечает только запросам с `thestarth.com`, а роль проверяет сам через Firestore от имени вошедшего человека:
- **Админ** (есть в коллекции `admins`) может составлять тесты;
- учителя, ученики и гости ИИ вызвать не могут. Размер запроса ограничен.

## 4. Как работает выбор мока у ученика (v22)

На странице Mock Exam ученик сначала выбирает раздел: **Полный мок**, **Listening**, **Reading** или **Writing**. Дальше он видит **все опубликованные** тесты этого раздела, выбирает один, и затем решает весь раздел или одну часть (Part / текст / Task).

- Админ добавляет тесты по одному (Listening, Reading, Writing) или собирает **Полный мок** из трёх уже созданных тестов (три выпадающих списка).
- Полный мок идёт по порядку Listening → Reading → Writing, в конце общий итог. Listening в режиме экзамена: аудио один раз.
- Writing: счётчик слов, таймер, черновик сохраняется. Работа уходит учителю.

## 5. Проверка Writing (кабинет учителя, вкладка «Проверка Writing»)

Всё делает учитель вручную, без ИИ и без автоматических проверок на списывание или ИИ-текст:
1. Открывает работу ученика из списка.
2. Ставит оценку по четырём критериям IELTS (шаг 0.5). Итоговый band считается по правилам IELTS: среднее четырёх критериев с округлением до .5; весь Writing = (Task 1 + 2 × Task 2) / 3.
3. Пишет сильные и слабые стороны, исправления «было → стало», комментарий.
4. Нажимает «Отправить ученику». Ученик видит разбор в «Мои результаты».
