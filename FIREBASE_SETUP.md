## v92 — партнёры-организации, журнал посещаемости, олимпиада по всему Узбекистану — ОБЯЗАТЕЛЬНО

1. **Firestore → Rules**: вставьте целиком новый `firebase-backend/firestore.rules` → **Publish**.
   Без этого не сохранится посещаемость, регистрация на олимпиаду и партнёры.
2. **Партнёры** (Админ-панель → «Партнёры» → «+ Создать партнёра»): название, никнейм куратора, никнеймы учителей.
   - Куратор партнёра тоже ведёт уроки и получает свою админ-панель (только свои учителя, группы, журнал, посещаемость).
   - У учителей партнёра нет раздела «Зарплата». «+1 месяц / +3 месяца / +7 дней» продлевает доступ всем сразу.
   - Создавать партнёров и менять куратора может только «Админ».
3. **Посещаемость** — журнал как в школе (месяц × дни уроков). Учитель отмечает **только сегодняшний** урок.
   Прошлые и будущие дни отмечает куратор: Админ-панель → «Посещаемость» (есть у «Админ», «Куратор TheStarth»,
   «Куратор (партнёр)»). Правила Firestore проверяют то же самое — обойти с телефона нельзя.
   Дни уроков берутся из расписания группы (например «Пн Ср Пт 18:00»).
4. **Олимпиада**: в редакторе появились классы (с–по), регистрация (регион, район, школа, класс), перемешивание
   вопросов и вариантов, «сдать автоматически после N уходов со страницы». Кнопка «Регистрации» — сколько человек и
   из каких регионов записалось заранее. В результатах — фильтры по региону и классу, место в регионе, «сколько решили
   каждый вопрос», Excel. Участник после публикации результатов скачивает сертификат (PDF через «Печать»).
   Совет: откройте регистрацию за 1–2 недели — у Firebase лимит 100 новых аккаунтов в час с одного IP.
5. Залейте все файлы на GitHub (версия скриптов — `?v=92`).

## v91 — кураторы (TheStarth и партнёр) и онлайн-олимпиада — ОБЯЗАТЕЛЬНО

1. **Firestore → Rules**: вставьте целиком новый `firebase-backend/firestore.rules` → **Publish**.
2. **Кураторы** (Админ-панель → «Ученики и роли», первый список у человека):
   - **Куратор TheStarth** — видит всех учителей и все группы (в том числе партнёров): контроль учителей, ученики и роли,
     журнал оценок, группы (создание, ученики, учитель), расписание, журнал уроков. Зарплат, сайта, промокодов нет.
   - **Куратор (партнёр)** — входит в админ-панель (кнопка «Админ-панель» появится у него на сайте), но видит только
     учителей, прикреплённых к нему, и их группы, уроки, посещаемость и оценки. У учителя (или учителя-партнёра) во втором
     списке выберите «Куратор: <имя>» — вся прошлая история учителя сразу станет видна этому куратору.
   - Назначать кураторов может только «Админ».
3. **Олимпиада**: Админ-панель → «Олимпиада» → «Новая олимпиада» → вопросы (можно «Вставить списком») →
   «Сохранить, подтвердить и опубликовать». На главной под кнопками появится «Олимпиада», страница — `olympiad`.
   После окончания: «Результаты» → «Опубликовать результаты».
4. Залейте все файлы на GitHub (версия скриптов — `?v=91`).
