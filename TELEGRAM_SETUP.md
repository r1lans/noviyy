# Telegram-напоминания об уроках (за 60 / 30 / 5 минут)

Как это работает: при регистрации (или в профиле) человек указывает Telegram-ник. Потом он один раз открывает бота и нажимает **Start** —
бот запоминает его. Каждую минуту маленький сервис (Cloudflare Worker, бесплатно) смотрит расписание и шлёт напоминания.
Бот не может писать человеку по одному нику — только после нажатия Start. Это ограничение Telegram.

## ВАЖНО про токен
Токен бота — это пароль от бота. **Нельзя** класть его в файлы сайта, в GitHub, в чат. Он хранится только в секретах Worker.
Если токен уже попал в чат или в репозиторий — откройте @BotFather → `/revoke` → выберите бота → получите **новый** токен и используйте его.

## Шаги (один раз, ~15 минут)

1. **Бот.** @BotFather → `/newbot` (или ваш существующий) → токен. Старый, засвеченный токен отзовите: `/revoke`.
2. **Ключ Firebase.** Firebase Console → ⚙ Project settings → Service accounts → *Generate new private key* → скачается `.json`. Не публикуйте его.
3. **Cloudflare.** dash.cloudflare.com → Workers & Pages → Create → Worker → вставьте код из `worker/telegram-reminders.js` → Deploy.
4. **KV.** Workers & Pages → KV → Create namespace `starth-tg`. В Worker → Settings → Bindings → Add → KV namespace → имя переменной **TG** → выберите `starth-tg`.
5. **Секреты** (Worker → Settings → Variables and Secrets → Add → тип *Secret*):
   - `TELEGRAM_BOT_TOKEN` — токен бота (новый!)
   - `TELEGRAM_WEBHOOK_SECRET` — любая случайная строка из латиницы и цифр (20+ символов)
   - `FIREBASE_SERVICE_ACCOUNT` — **весь текст** скачанного `.json`
6. **Cron.** Worker → Settings → Trigger Events → Cron Triggers → Add → `* * * * *` (каждую минуту).
7. **Настройка бота одной ссылкой.** Откройте в браузере (один раз):
   `https://<ваш-worker>.workers.dev/setup?key=<TELEGRAM_WEBHOOK_SECRET>`
   Она сама подключит webhook, добавит меню команд (RU/UZ/EN) и описание бота. Должно вернуться `"ok": true` в блоках webhook/commands.
8. **Имя бота на сайте.** В `firebase-config.js` впишите `window.STARTH_TG_BOT = 'ИмяВашегоБота';` (без токена!) — оно покажет ссылку на бота в профиле.
9. Опубликуйте `firebase-backend/firestore.rules` (Firebase → Firestore → Rules → Publish).

## Проверка
Поставьте себе урок через 6 минут (Админ-панель → Расписание, время по Ташкенту), в профиле укажите свой @username, нажмите Start у бота — через минуту придёт «Урок через 5 минут».

## Что считается уроком
- разовые уроки из расписания (`schedule`: дата + время) — ученику и учителю;
- уроки групп (`groups`: дни недели + время) — всем участникам группы и учителю.
Время — Ташкент (UTC+5). Один и тот же урок не напоминается дважды.
Команда `/stop` у бота отключает напоминания, `/start` включает снова.

## Что умеет бот
- `/start` — подключиться (бот запоминает ник), `/stop` — выключить напоминания.
- Напоминания об уроках за 60, 30 и 5 минут (ученикам и учителям, разовые уроки и уроки групп).
- `/today` — уроки на сегодня, `/schedule` — уроки на 7 дней.
- `/lang` — язык бота (русский / o‘zbekcha / English), `/site` — кнопки со ссылками на сайт и кабинет, `/help` — помощь.

## Идеи на потом (если захотите)

- Напоминание о невыполненном домашнем задании и о пропущенном уроке.
- Ссылка «Войти в урок» прямо в напоминании за 5 минут.
- Рассылка объявлений от админа всем, кто подключил бота.
- Напоминание об оплате.
