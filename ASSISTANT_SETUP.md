# ИИ-помощник на сайте (кнопка чата справа внизу)

Помощник отвечает посетителям на вопросы о TheStarth: курсы, форматы, цены, учителя, как проходят уроки,
оплата, скидки, как записаться. Понимает русский, узбекский и английский. Можно спрашивать голосом (кнопка
микрофона) и слушать ответы (кнопка динамика в шапке чата; появляется, если в браузере есть голос для этого языка).

Цены и список учителей он берёт из Firebase сам — после изменений в админке помощник узнаёт о них в течение 10 минут.
Остальные факты (контакты, как проходят уроки, скидки, оплата) записаны в `worker/mock-ai-worker.js`, блок `KB`.
Если что-то из этого поменялось — поправьте текст там и снова нажмите Deploy в Cloudflare.

Пока в `mock-config.js` не вписан адрес посредника, кнопки чата на сайте нет — ничего не сломается.

## Как включить (бесплатно, ~10 минут, один раз)

Посредник тот же, что и для мок-тестов. Если вы его уже создали — достаточно заменить в нём код (шаг 3) и проверить шаг 5.

1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно).
2. **Workers & Pages → Create → Create Worker**. Назовите `starth-ai` → **Deploy**.
3. **Edit code** → удалите всё → вставьте содержимое файла `worker/mock-ai-worker.js` → **Deploy**.
4. **Settings → Bindings → Add → Workers AI**, имя переменной строго `AI` → **Deploy**.
   (Это бесплатный ИИ Cloudflare с дневным лимитом. Если позже захотите качество лучше, особенно на узбекском, —
   добавьте секрет `ANTHROPIC_API_KEY`, см. MOCK_SETUP.md, раздел 3.1. Тогда помощник будет работать на Claude.)
5. **Settings → Variables and Secrets → Add**, тип **Text**:
   `ALLOWED_ORIGIN` = `https://thestarth.com,https://r1lans.github.io`
   (адреса, с которых открывается сайт, через запятую) → **Deploy**.
6. Скопируйте адрес посредника вверху страницы — вида `https://starth-ai.ВАШ-АККАУНТ.workers.dev`.
7. Откройте `mock-config.js`, впишите адрес и залейте файл на GitHub:

```js
window.MOCK_AI_URL = 'https://starth-ai.ВАШ-АККАУНТ.workers.dev';
```

Готово: на сайте справа внизу появится круглая кнопка чата.

## Защита
- Отвечает только запросам с адресов из `ALLOWED_ORIGIN`.
- Не больше 30 сообщений за 10 минут с одного устройства, длина вопроса до 600 символов, ответ короткий.
- Отвечает только про TheStarth; на посторонние просьбы (решить домашку, написать эссе) вежливо отказывает и предлагает пробный урок.
- Если чего-то не знает — не выдумывает, а предлагает связаться с куратором (телефон / Telegram) или оставить заявку.

## Голосовой звонок с помощником
В чате есть кнопка с трубкой (и «📞 Поговорить голосом»): человек говорит — помощник отвечает голосом — снова слушает, как в телефонном разговоре.
Нажатие на круг во время ответа — перебить; кнопка микрофона — выключить микрофон; красная — завершить. Работает в Chrome, Edge и Safari.

**Голос по умолчанию (бесплатно)** — голос браузера; сайт сам выбирает самый естественный («Natural», «Online», «Google»).
Лучше всего звучит в Microsoft Edge и Chrome. На узбекском у многих телефонов голоса нет.

**«Живой» голос (как человек, есть узбекский) — Microsoft Azure, по желанию:**
1. https://portal.azure.com → создать ресурс **Speech service** (Azure AI services → Speech). Тариф **Free F0** (бесплатный месячный лимит; нужна регистрация с картой). Регион, например, **West Europe**.
2. Ресурс → **Keys and Endpoint** → скопировать **KEY 1** и **Location/Region** (например `westeurope`).
3. Cloudflare → воркер `starth-ai` → Settings → Variables and Secrets:
   - `AZURE_SPEECH_KEY` — тип **Secret** — ключ;
   - `AZURE_SPEECH_REGION` — тип Text — регион, например `westeurope` → **Deploy**.
Готово: сайт сам начнёт говорить голосами Azure (RU — Светлана, UZ — Мадина, EN — Ava). Другие голоса можно задать переменными `VOICE_RU`, `VOICE_UZ`, `VOICE_EN`.

## ИИ Support Teacher (страница ai-teacher, кабинет → «ИИ-ассистент», панель «ИИ-учитель» на видеоуроке)

ИИ-ассистент ученика состоит из двух частей (переключатель вверху страницы):
- **ИИ Support Teacher** — помогает учиться, а не решает за ученика:
  объясняет тему простыми словами с примерами и типичной ошибкой; с домашним заданием даёт подсказки и наводящие вопросы
  (готовый ответ, эссе или решение не выдаёт, но может разобрать похожий пример); проверяет решение ученика и показывает,
  где ошибка; после объяснения сам предлагает **мини-тест** (5 вопросов с разбором), а кнопка «Проверь меня» делает тест
  по любой теме. После теста — «Разобрать мои ошибки». Результаты тестов видят ученик (кабинет) и учитель (журнал).
- **ИИ Speaking** — прежняя тренировка IELTS Speaking (speaking.html).

Доступ: ученики, которые состоят в группе, учителя и админы (как у Speaking). Переписка хранится на устройстве ученика.
На видеоуроке кнопка «ИИ-учитель» открывает его сбоку, не выходя из урока (там же кнопка «Сообщения» — мессенджер кабинета).

Включение: ничего отдельно — тот же воркер `starth-ai`. Достаточно залить новый `worker/mock-ai-worker.js` (Edit code → Deploy).
Необязательные переменные воркера:
- `TUTOR_MODEL` — модель для ответов (по умолчанию `claude-haiku-5-5`); тесты составляет `MODEL` (по умолчанию `claude-sonnet-5-5`).
- `TUTOR_DAILY` — сколько сообщений ИИ-учителю в день на ученика (по умолчанию 80; нужен KV `LIMITS`, как для Speaking).
Без `ANTHROPIC_API_KEY` работает и на бесплатном Workers AI, но объяснения и тесты заметно лучше на Claude.
